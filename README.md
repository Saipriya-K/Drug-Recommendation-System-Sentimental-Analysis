# Drug-Recommendation-System-Sentimental-Analysis
DRUG RECOMMEDATION SYSTEM BASED ON SENTIMENT ANALYSIS  ON DRUG REVIEW USING MACHINE LEARNING
Drug Recommendation System Based on Sentiment Analysis

Project Overview

This project focuses on developing a Drug Recommendation System by analyzing user reviews using Sentiment Analysis and Machine Learning techniques.

The system processes drug reviews, performs text preprocessing, extracts useful textual features using TF-IDF, and applies Machine Learning techniques to analyze the sentiment of drug reviews.

Technologies Used

- Python
- Pandas – Dataset loading and manipulation
- NumPy – Numerical operations
- NLTK – Text preprocessing
- Scikit-learn – TF-IDF, Naive Bayes, and evaluation metrics
- Matplotlib – Data visualization and pie chart
- Seaborn – Confusion matrix heatmap
- Regular Expressions ("re") – Text cleaning

Machine Learning Techniques

- Text Preprocessing
- Natural Language Processing (NLP)
- Sentiment Analysis
- TF-IDF Feature Extraction
- Naive Bayes
- Model Evaluation

Dataset

The project uses a drug review dataset containing information about drugs, user reviews, and related review details.

Project Workflow

1. Load the drug review dataset
2. Perform data preprocessing
3. Clean and prepare the review text
4. Perform text processing using NLTK
5. Convert text into numerical features using TF-IDF
6. Train the Naive Bayes Machine Learning model
7. Evaluate the model performance
8. Analyze sentiment from drug reviews
9. Provide sentiment-based insights for drug recommendations

Project Objective

The main objective of this project is to use Natural Language Processing and Machine Learning techniques to analyze drug reviews and provide useful insights based on user sentiment.

Key Features

- Drug review data preprocessing
- Text cleaning and NLP processing
- Sentiment analysis of drug reviews
- TF-IDF-based feature extraction
- Machine Learning-based sentiment classification
- Model performance evaluation

Future Scope
